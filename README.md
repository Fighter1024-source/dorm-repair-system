# dorm-repair-system 宿舍报修系统
✨ 个人全栈练习作品 | SpringBoot + MySQL + 前端页面

## 🧩 项目功能
- 👨‍🎓 学生端：提交维修申请、上传报修图片、查看工单进度
- 🔧 维修员端：接收工单、处理报修、修改工单状态
- ⚙️ 管理员端：工单ECharts可视化统计、查看全部工单、用户管理
- 🔐 登录注册：学生 / 维修人员 / 管理员 三种角色权限隔离

## 🛠 技术栈
后端：Java SpringBoot、MyBatis-Plus、MySQL
前端：HTML + CSS + JavaScript、ECharts图表库

## 📄 前端页面清单
- login.html 登录页面
- register.html 注册页面
- student.html 学生报修工作台
- repairman.html 维修人员工作台
- admin.html 管理员后台

## 🚀 运行说明
1. 导入SpringBoot后端项目，修改数据库配置并启动服务
2. 浏览器访问前端页面进行操作
